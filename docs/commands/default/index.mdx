<Info>
All default commands available in Fossabot are documented here!
</Info>

Default commands are built-in commands that come with every Fossabot installation. These commands provide essential functionality for streamers and their communities.

## Available Commands

### Information Commands

* [**!commands**](/commands/default/commands) - Provides a link to view all channel commands
* [**!game**](/commands/default/game) - Shows the current game being played
* [**!gamesplayed**](/commands/default/gamesplayed) - Shows all games played during the current stream with durations
* [**!ping**](/commands/default/ping) - Shows how long Fossabot has been online
* [**!title**](/commands/default/title) - Shows the current stream title
* [**!uptime**](/commands/default/uptime) - Shows how long the current stream has been live

### User Information Commands

* [**!accountage**](/commands/default/accountage) - Shows how long ago a user created their account
* [**!accountdate**](/commands/default/accountdate) - Shows the date when a user created their account
* [**!followage**](/commands/default/followage) - Shows how long one user has been following another
* [**!followdate**](/commands/default/followdate) - Shows the date when one user followed another

### Entertainment Commands

* [**!clip**](/commands/default/clip) - Creates a clip of the current stream on Twitch
* [**!dadjoke**](/commands/default/dadjoke) - Returns a random dad joke
* [**!eightball**](/commands/default/eightball) - Returns a random response from the magic 8-ball
* [**!fact**](/commands/default/fact) - Returns a random interesting fact
* [**!vanish**](/commands/default/vanish) - Times out the command sender for 5 seconds
* [**!votekick**](/commands/default/votekick) - Starts a vote kick poll to remove a user from chat

### Dictionary Commands

* [**!dictionary**](/commands/default/dictionary) - Looks up word definitions
* [**!urbandictionary**](/commands/default/urbandictionary) - Looks up words and phrases in Urban Dictionary

### Emote Commands

* [**!emotes**](/commands/default/emotes) - Displays channel emotes from various providers

### Media Request Commands

* [**!song**](/commands/default/song) - Displays the currently playing track in the media request queue
* [**!sr**](/commands/default/sr) - Adds a track to the media request queue using a URL or search query
* [**!clear**](/commands/default/clear) - Clears the entire media request queue
* [**!songqueue**](/commands/default/songqueue) - Provides a link to view the current media request queue
* [**!skip**](/commands/default/skip) - Skips the currently playing track in the media request queue
* [**!volume**](/commands/default/volume) - Displays or sets the playback volume for media requests
* [**!voteskip**](/commands/default/voteskip) - Votes to skip the currently playing track
* [**!wrongsong**](/commands/default/wrongsong) - Removes your most recently requested track from the media request queue

### Management Commands

* [**!addcmd**](/commands/default/addcmd) - Creates a new custom command
* [**!clip**](/commands/default/clip) - Creates a clip of the current livestream
* [**!cmd**](/commands/default/cmd) - Comprehensive command management system
* [**!count**](/commands/default/count) - Manages custom counters for the channel
* [**!delcmd**](/commands/default/delcmd) - Deletes a custom command
* [**!editcmd**](/commands/default/editcmd) - Modifies an existing custom command
* [**!filesay**](/commands/default/filesay) - Reads and sends messages from a text file to chat
* [**!filesaystop**](/commands/default/filesaystop) - Stops the currently running filesay operation
* [**!nuke**](/commands/default/nuke) - Removes messages containing a specific phrase from chat
* [**!permit**](/commands/default/permit) - Temporarily prevents a user from being timed out
* [**!quote**](/commands/default/quote) - Displays and manages channel quotes
* [**!setcommand**](/commands/default/setcommand) - Creates or updates a custom command
* [**!setgame**](/commands/default/setgame) - Changes the current game being played
* [**!settitle**](/commands/default/settitle) - Changes the current stream title

## Usage

All default commands can be used by typing the command name in chat, followed by any required parameters. Some commands have additional sub-commands for extended functionality.

## Permissions

Most default commands are available to all users. Commands that require special permissions are clearly marked in their documentation.
