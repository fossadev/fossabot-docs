Variables offer inline, dynamic text replacement for Fossabot responses.

## Usage

Use the `$()` syntax within your chat responses to insert dynamic data.

For example, [**\$(sender)**](/variables/sender) allows you to mention the name of the user triggering the action, you may choose to invoke this variable within a command such as `Hello, $(sender)!`. See the below example for more details.
