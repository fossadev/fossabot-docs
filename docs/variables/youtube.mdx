Returns metadata about the latest YouTube video of a channel or a playlist that can be accessed via multiple different variable members.

**We use YouTube API Services to query data that powers this variable. Use of this variable is subject to the [Google Privacy Policy](https://policies.google.com/privacy) and [YouTube Terms of Service](https://www.youtube.com/t/terms)**

## $(youtube)

Returns the title and URL of the latest YouTube video of a channel or a playlist.

#### Parameters

This variable takes **one** *required* parameter that is either a **channel name**, **channel ID** or **playlist ID**. Prefix a playlist ID with `playlist=`.

#### Example Output

* `$(youtube Fossabot)`

    ```
    Getting started with Fossabot - https://youtu.be/VIDEO_ID
    ```

* `$(youtube playlist=PLAYLIST_ID)`

    ```
    Getting started with Fossabot - https://youtu.be/VIDEO_ID
    ```

#### Error Output

* In case the channel cannot be found, returns the following:

    ```
    [Error: Channel not found]
    ```

* In case no public, non-livestream videos are found, returns the following:

    ```
    [Error: No videos found]
    ```
